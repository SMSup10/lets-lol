# LOL Quiz v3.5 — Little Rift Club 💗

11가지 퀴즈 유형: 초상화, 스킬 아이콘, 스킬 이름, 일러스트 조각, 롤 상식, 챔피언 실루엣, 스킬 설명, 스킨 이름, 아이템 아이콘, e스포츠 상식, 스킬 조합.

## 디자인
파스텔 핑크/라벤더 테마. 유형은 **챔피언 알아맞히기 / 지식 퀴즈** 그룹의 컴팩트한 카드로 선택. 그룹별 선택 버튼 제공. 사용하지 않는 난이도 설정 자동 숨김.

## 데이터
- `trivia.json`: 기존 상식 97문제
- `esports.json`: 역사 기반 e스포츠 상식 20문제
- 스킬 설명·조합·스킨·아이템: Riot Data Dragon 데이터 이용(최초 인터넷 연결 필요)
- 실루엣: 기본 로딩 일러스트에 검은 실루엣 필터 적용

## 배포
ZIP을 압축 해제하여 `index.html` 등이 저장소 루트에 오도록 GitHub Pages에 업로드. 기존 진행 기록은 유지됨.

## 주의
공식 게임/이스포츠 서비스가 아닌 비공식 팬 프로젝트. 스킨·아이템 데이터는 패치에 따라 변할 수 있음. e스포츠 문제는 2023년까지의 역사 기록 위주. 데이터 드래곤 스킬 설명의 일부 서식은 단순 텍스트로 정리됨.
